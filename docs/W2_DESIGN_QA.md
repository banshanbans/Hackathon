# W2 H5 设计 QA

## 设计来源与边界

W2 延续现有颜色、圆角、间距和排版 token。页面信息层级参考已确认的概览图；`stitch_ui_visual_replication/` 仅用于视觉和信息架构启发，没有复制其静态跳转、远程资产、CDN 依赖、假数据能力或未经验证的平台声明。

## 已验证项目

- 固定路由覆盖入口、参考、约束、分析、现场、ShotPlan、两轮拍摄、两轮评价和结果页。
- 预设与自定义参考都经过同一个真实圈选交互；坐标采用左上角原点 `[0,1]`，纯函数测试覆盖 `object-fit: contain` 留白、横竖图、拖动、缩放和重置。
- 390×844 移动视口没有横向溢出，主要点击区域至少 44px。
- 键盘焦点可见；状态和错误不只依赖颜色；动画遵守 `prefers-reduced-motion`。
- 上传支持进度、取消、失败重试，并始终保留文件选择作为可靠后备。
- `Fixture`、`Live`、`Fallback` 和 `Error` 状态在页面上可见。
- Fixture 结果不伪造照片配对；Live 结果只使用本 Session 的真实上传。
- 刷新恢复覆盖分析、ShotPlan、评价和结果阶段；未提交的本地媒体会明确要求重选。

## 自动化覆盖

Playwright 在移动 Chromium 390×844、移动 WebKit 390×844 和桌面 Chromium 1280×900 中覆盖：

- 预设 Fixture 两轮全流程与多阶段刷新恢复。
- 自定义原图复刻 Live mock 两轮媒体流程。
- 预设场景适配 Live mock。
- 自定义场景适配 Live mock。

## 仍需设备验证

- 真实 iOS Safari 与 Android Chrome 的相机权限、拍照和相册选择。
- 不同设备对 HEIC、旋转 EXIF 和短视频抽帧的兼容性。
- 低内存设备处理接近 100MB 视频时的表现。
- 弱网、后台切换和系统文件选择器中断后的恢复。

这些项目必须记录真实设备型号、系统版本和浏览器版本；桌面模拟不能作为设备验收的替代。
