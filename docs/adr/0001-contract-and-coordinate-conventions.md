# ADR 0001：共享契约与坐标约定

- 状态：已接受
- 日期：2026-07-16

## 背景

SoloShot AI 包含 H5 客户端、iOS 客户端和 Python API。如果允许每个客户端自行定义会话、问题代码或坐标系统，跨设备接力将变得不可靠。

## 决策

- `packages/contracts/` 下的 OpenAPI 3.1 和 JSON Schema 2020-12 是跨客户端的唯一事实来源。
- 公共 DTO 使用 `schema_version: "1.0"`。
- 归一化坐标范围为 `[0,1]`，原点位于左上角；x 轴向右增长，y 轴向下增长。
- Vision 原生坐标在 iOS 边界处完成转换，之后才能进入共享领域模型。
- 生成的 H5 和 Swift 类型需要提交到仓库，并通过 `make generate` 重新生成；不得手动编辑。
- 写操作必须提供幂等键；成功响应公开请求 ID；错误使用稳定的错误代码。

## 影响

契约发生变更时，必须在同一次变更中重新生成两个客户端，并通过契约测试。W4 开始 Vision 相关工作时，必须集中管理 iOS 坐标映射逻辑。
